# Screenshots & Lab Evidence

This folder contains visual evidence from networking labs and troubleshooting exercises.

## Evidence Types

- Network topology screenshots
- Device configuration screenshots
- Verification output
- Connectivity tests
- Troubleshooting evidence
- Failure symptoms
- Recovery validation

## Naming Convention

Use descriptive filenames, for example:

- `lab-01-topology.png`
- `lab-01-device-config.png`
- `lab-01-verification.png`
- `lab-01-failure.png`
- `lab-01-recovery.png`

## Security

Do not upload:

- Passwords
- API keys
- Tokens
- Private credentials
- Sensitive personal information

Screenshots should be sanitized before being committed to the public repository.
