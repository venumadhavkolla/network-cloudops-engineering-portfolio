# Network Diagrams

This folder contains network topology and architecture diagrams created during the roadmap.

## Diagram Types

- Packet Tracer topologies
- Network architecture diagrams
- VLAN / segmentation diagrams
- Routing diagrams
- Troubleshooting diagrams
- Project architecture diagrams

## Naming Convention

Use descriptive filenames, for example:

- `lab-01-basic-topology.png`
- `lab-02-switching-topology.png`
- `project-01-campus-network.png`

## Documentation

Each important diagram should identify:

- Devices
- Connections
- Interfaces
- IP addresses, where relevant
- VLANs, where relevant
- Network relationships
- Important configuration details

## Security

Do not include:

- Passwords
- API keys
- Tokens
- Private credentials
- Sensitive personal information
