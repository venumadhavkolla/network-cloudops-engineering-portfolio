# Month 1 — Networking Foundations

**Period:** September 16, 2026 → October 15, 2026

## Objective

Build a strong foundation in computer networking and begin CCNA v2 preparation through hands-on practice.

## Focus Areas

- Networking fundamentals
- Network devices and their roles
- Basic network connectivity
- Ethernet fundamentals
- IPv4 addressing
- Basic subnetting
- Introduction to network troubleshooting
- CCNA v2 foundational concepts

## Labs

Target: **8 deep labs**

Each deep lab should include:

1. Guided build
2. Independent rebuild 24–72 hours later
3. Failure injection 3–14 days later
4. Troubleshooting and recovery
5. Documentation and evidence

## Daily Documentation

Each study day should document:

- Topics studied
- Labs completed
- Commands/configurations practiced
- What was understood
- Questions or weak areas
- Troubleshooting performed
- Evidence/screenshots
