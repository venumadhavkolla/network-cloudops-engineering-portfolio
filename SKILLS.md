## Evidence Standard

A skill should only be changed from **Not Started** when there is supporting evidence in the repository.

Possible evidence:

- Lab
- Configuration
- Screenshot
- Packet capture
- Troubleshooting record
- Incident
- RCA
- Runbook
- Automation script
- Project
- Demo

## Status Definitions

- **Not Started** — No hands-on evidence yet
- **Learning** — Currently studying/practicing
- **Practiced** — Completed hands-on practice
- **Demonstrated** — Successfully demonstrated through a documented lab/project/incident
